# サンプルカードリスト v5.2(全53種・実験版)

**注意: v5.2は検証・テストプレイ中の実験版(ルールブックv1.5.2対応)。**

構成: N 27種(モンスター19+魔法・罠8)/ R 13種(モンスター9+魔法・罠4)/ SR 8種(モンスター5+魔法・罠3)/ UR 5種(神3+御業2)

v5.2変更点(召喚統合): ブースト召喚の廃止(召喚への統合・「以下」ルール化)に伴い、供物3種の効果文を「召喚のリリースとして」に改訂。可変星2種は「以下」ルールでは最大値以外を選ぶ意味がないため「星3(/5)として扱える」に簡素化。
v5変更点(手札リリース制限): ブースト召喚のリリースが場のモンスター限定になったことに伴い、★1〜3のバニラから各1種(豆狸・人魚姫・一反木綿)に**供物効果「ブースト召喚のリリースとして、手札からリリースできる」**を付与。種数・ステータスの変更なし。
v4変更点(除去再編): 鬼退治をN→SR、落とし穴をR→SR、神隠しをN→R、天罰・アイギスの盾をSR→UR「神の御業」へ移動。Nに弱体化系3種(神便鬼毒酒・砂かけ婆・お焚き上げ)を新設。草薙剣の持続を「次の相手ターンの終了時まで」に延長。
v3変更点: 鬼火・ぬりかべに戦闘強化関連の効果を付与。
v2変更点: 可変星モンスター「化け狸」(N26)「鵺」(R13)を追加。

凡例: 攻/守=攻撃力/守備力。効果のないものはバニラ。

## 設計メモ

- **v5の設計思想**: 「神への供物は、一度この世(場)を経由せよ」。手札2枚が盤面に触れずに神へ変換される手札完結ルートを廃止し、リリース素材を場に立てる中継ターン(=相手の攻撃・除去のチャンス)を作った。例外となる供物モンスター3種は**各星のバニラ最弱ステータス**から選び、効果でピック価値を補強する(鬼火・ぬりかべと同じ「弱いカードに役割を与える」路線)
- **供物モンスターのフレーバー**: 人魚姫=自らの身を泡に変えて捧げる自己犠牲。豆狸=主の身代わりに化ける小狸。一反木綿=神を包んで天へ運ぶ依り代の布
- **供物と可変星の役割分担(v5.2)**: 供物(豆狸・人魚姫・一反木綿)は「手札から直接」捧げられる。可変星(化け狸・鵺)は自身の星より大きい星を生み出せるが**場に出してから**しか捧げられない。「以下」ルールでは星の照準合わせが不要になったため、可変星の価値は「格上の星として数えられる」点に集約された
- **v4の設計思想**: 「大型モンスターは破壊で消すのではなく、弱体化と戦闘で打ち倒す」。破壊系は希少な切り札(SR単体/UR複数)に格上げし、日常の対抗手段は数値の増減に交代した。実測で★6以上の死因は魔法罠1.39体→0.51体/試合へ激減し、戦闘死(0.77体)が主役になった
- **弱体化の数値設計**: 毒酒の-700は「R最上位(1900)がSR最上位(2500)を単騎撃破できる」値。UR(3000)は毒酒+草薙剣や戦闘強化との**2枚コンボでのみ**届く——格上ほど多くの手数を要求する
- **答え確定枠の交代**: 払い清め・金縛り・死者の声・神便鬼毒酒・砂かけ婆の5種。「どのパックにも対抗札がある」原則は維持しつつ、答えの性質が変わった。1/16で神の御業に化けるジャックポットつき
- **鬼火・ぬりかべ**は戦闘強化ルールの特例カード。鬼火は「炎が武器に宿る」奇襲の一撃(攻撃専用)、ぬりかべは「砕けて盾になる」守りの壁(守備表示専用)。お焚き上げ×鬼火=+2000の浪漫コンボあり
- **可変星モンスター**(化け狸・鵺)は、自身の星より高い星を生み出すリリース素材。鵺は猿・狸・虎・蛇の合成獣であり「化ける」フレーバーを担う
- **リリースの階段**: 小型を場に出し、次のターン以降にリリースして大型へ乗り換える(ターンをまたいで登る)。「以下」ルールでは星の組み合わせを問わない
- **壁役**(豆狸・ろくろ首・ぬりかべ・弁慶)は守備表示ルールの受け皿。豆狸は「場で壁/手札で供物」の2役を持つ
- URの神は3種とも効果なし・耐性なしの「裸の巨人」。攻守合計はほぼ同じ(5500前後)にして、どれを引いても当たりの満足度が揃えてある
