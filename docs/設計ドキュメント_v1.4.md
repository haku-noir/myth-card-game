## 5. 戦闘フロー(gameEngine.ts)

```
declareAttack(攻撃宣言、攻撃権消費)
  ↓ 攻撃側の手札にモンスターがあれば
pending: attackerBoost ── respondBoost(handIdx | null)
  捨てたモンスターの星×100を攻撃力に加算(この戦闘の間)
  特例: 鬼火=+1000 / お焚き上げ中=2倍
  ↓
pending: defenderReaction ── respondReaction({trap,zone} | {boost,handIdx} | null)
  罠1枚 または 戦闘強化 のどちらか一方(v1.3: 罠は攻撃側の強化を見てから)
  - 金縛り: 攻撃無効 / 神隠し: 攻撃側を手札へ / アイギス: 攻撃表示全破壊
  - 砂かけ婆: 攻撃側-600(ターン終了時まで)→戦闘続行
  - 背水の陣: 手札から壁を出して攻撃をリダイレクト(攻撃側の強化値は維持)
  - 強化: 攻撃表示=攻、守備表示=守に星×100加算(ぬりかべ=守備時+800)
  ↓
resolveBattle(BattleContextのboost込みでダメージ計算)
```

## 6. CPU AIの要点(cpu.ts)

- 召喚: 通常召喚の最良とぴったりブーストの最良(純益=召喚打点-リリース損失)を比較
- 攻撃側強化: トドメ・劣勢の逆転時のみ。鬼火は安く扱い積極消費
- 防御側リアクション: 罠を優先度順に閾値評価→不発なら返り討ち可能な強化
- 神便鬼毒酒: -700で自軍最強が相手最強を上回れる時に使用
- 難はお焚き上げ×鬼火コンボと強化込み打点での攻撃判断を行う

- CPU総当たり500ゲーム: クラッシュ・無限ループ・カード総数異常なし

- PvP・ブースタードラフトのヘッドレス回帰テスト全件成功
