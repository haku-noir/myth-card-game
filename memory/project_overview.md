カードゲームWebアプリ「星の階(ほしのきざはし)」をDockerで構築する。

**Why:** ルールブック・カードリストのドキュメントからWebアプリを実装する。2026-06-12にv1.0→v1.4へ全面更新した(v1.1〜v1.3はスキップして累積実装)。

**How to apply:** 実装時は docs/設計ドキュメント_v1.md(全体構成)と docs/設計ドキュメント_v1.4.md(v1.4差分)を参照する。カードは全53種(N27/R13/SR8/UR5)。レアリティ移動したID: 鬼退治=SR9、落とし穴=SR10、神隠し=R14、天罰=UR4、アイギスの盾=UR5。

## 技術スタック
- フロントエンド: React + TypeScript + Vite + Tailwind CSS + Zustand + immer
- バックエンド: Node.js + Express + TypeScript + Socket.io
- DB: SQLite + Prisma
- Docker: docker-compose でフロント(port:3000) / バック(port:4000) を分離

## ゲームルール概要(v1.4)
- 初期ライフ8000、先攻レベル1スタート・後攻レベル2スタート
- 召喚は1ターン1回。通常召喚(レベル以下) or ぴったりブースト召喚
  (手札/場の1体をリリースし「レベル+リリース星」と同星のみ)
- 可変星: 化け狸(★1〜3)・鵺(★1〜5)はリリース時に星を選べる
- 戦闘強化: 攻撃宣言→攻撃側が手札を捨て星×100加算→防御側は罠or強化の二者択一→計算
- バフは期限付き(ターン終了時まで/次の相手ターン終了時まで/この戦闘の間)
- チェーン処理なし。場: モンスター最大5体、罠最大3枚

## 実装モード
- CPU戦(難易度3段階: 易/普通/難)
- PvP(オンライン/ルームコード方式、N人対応設計、現在は2人固定)
- シールド戦ドラフト
- ブースタードラフト(4ラウンド×10ピック=40枚→20枚構築、N人対応設計)

## デッキ保存機能
作成済みデッキをSQLiteに保存。パック開封をスキップして保存デッキでゲーム開始可能。
上限10デッキ。CRUD API: /api/decks

## カード画像
現在なし。/public/images/cards/{cardId}.png に配置すれば自動適用される設計。
